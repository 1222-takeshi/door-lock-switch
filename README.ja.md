# door-lock-switch

玄関のサムターン錠を「施錠」方向に回す電池駆動の装置と、壁の照明
スイッチを物理的に押す小さな装置です。ESP32 と3Dプリントの取付部品
（FLASHFORGE Adventurer 3）で作ります。

English README: [README.md](README.md)

## 安全設計（必須要件）

1. 遠隔操作は**施錠のみ**。解錠は遠隔では行いません。ファームウェアに
   解錠のリモート経路は存在しません（WiFiは電池低下の通知送信専用）
2. 手動操作が常に優先。サーボ無通電時はフリーで、サムターンは手で
   そのまま回せます
3. 故障・通信断・電池切れのときはフリーに倒れ、締め出しにはなりません
4. 施錠の完了は回し切りスイッチで検出します（推測で済ませない）

## ハードウェア

| 役割 | 部品 |
|---|---|
| サムターン駆動 | MG946R（高トルク）＋印刷アダプタ |
| 照明スイッチ | 9gサーボ＋印刷した押しアーム |
| 制御 | ESP32開発ボード（deep sleep、ボタン/ドアセンサ/タイマーで起床） |
| 電源 | 電池：単3×4（6V）アルカリまたはニッケル水素×5。サーボ電源はFETで遮断 |

## 残バッテリー量の推定

分圧抵抗経由で電池電圧を測ります（無負荷時と施錠動作中の負荷時）。
残量は「電圧→放電曲線の換算」と「施錠回数の消費積算」の小さい方を
採用するハイブリッド方式で推定し、3段階（十分／低下／要交換）をLEDで
表示、低下時はWiFiで通知します。推定ロジックは依存なしのC++ヘッダ
（`firmware/battery_estimator.h`）にあり、ホスト側テスト付きです。
